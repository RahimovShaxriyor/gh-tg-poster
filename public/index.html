    GitHub

    Откуда брать коммиты. Нужен доступ только на чтение.

    GitHub App
    Подключить через GitHub App

    Подключено:

    Доступ к репозиториям

    Fine-grained токен: доступ к одному репозиторию, Contents — Read-only. Если подключён GitHub App, токен не используется.

    Список появится после подключения GitHub.

    Telegram

    Бот публикует посты в канал и присылает вам черновики в личку.

    Выдаёт @BotFather командой /newbot.

    Бот должен быть администратором канала с правом публикации. Если вы привязаны как владелец и добавите бота в канал сами, поле заполнится автоматически.

    Владелец бота

    Владелец получает черновики с кнопками и может писать боту /check и /status. Остальным бот не отвечает.

    ИИ

    Пишет текст поста по коммитам и изменениям в коде.

    Проверка и стиль

    Как часто смотреть в GitHub и как писать посты.

    Для дайджеста и для времени в ответах бота. Формат IANA, например Asia/Tashkent.

    Пост пишется, когда после последнего коммита прошла пауза: серия коммитов попадёт в один пост. Команда /check в боте паузу не ждёт.

    Безопасность

    После смены пароля все остальные сессии завершатся. Пароль из .env перестанет действовать; вернуть его можно командой из README.
